# RadGym v0.1 — Synthetic Case Curation Worksheet

**Status:** Working document for active curation. Delete or archive post-launch.
**Pairs with:** `METHODOLOGY.md` §2.7 (case distribution targets).
**Tracks:** the 175 remaining synthetic slots required to reach the 200-case v0.1 target after the Table 1 anchor sweep (cases 0001–0018) and Fleischner figure cluster (0019–0025).

---

## How to use this

Each row specifies the **algorithm-determining fields** for one synthetic case:

- **Nodule spec** — type, size (mm), multiplicity, and (for multiples) additional nodules.
- **Target risk class** — what `maintainer_assigned_risk` should be set to.
- **Min sufficient risk profile** — the minimum patient-field combination that yields the target risk class per oracle heuristic + your clinical judgment. You'll typically add more risk factors or pure-flavor demographics on top.
- **Boundary** — `⚑` marks a deliberate size-boundary case (5/6 mm or 8/9 mm threshold) — these are over-sampled per §2.7's last paragraph.
- **Indication hint** — suggested clinical context to vary case-to-case. Don't reuse the same one repeatedly within a bin; vary across cases.

What is **NOT pre-specified**, by design:

- Age and sex — vary across 35–90, both sexes.
- Specific clinical narrative — write the presentation in your own voice; vary indication, symptoms, prior-imaging framing, geographic/exposure flavor.
- Source string — `synthetic_maintainer_authored` for all rows here.
- Notes — leave empty unless something unusual about the case (boundary case acknowledged, deliberate risk-override, etc.).

**Order suggestion:** work bin-by-bin (stay in one algorithm branch at a time). Within a bin, work the boundary-flagged rows first (those are higher-information cases for benchmark sensitivity) then fill the rest.

**Marking progress:** edit the row to add the case ID once authored, e.g. `| 1 | … | RGYM-v01-0026 |` at the end, or just put `[x]` in the leftmost column.
